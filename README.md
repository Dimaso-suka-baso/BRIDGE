## 📖 Tentang BRIDGE

**BRIDGE** merupakan aplikasi komunikasi inklusif yang dikembangkan untuk menjembatani keterbatasan komunikasi antara penyandang tunanetra dan tunarungu.

Aplikasi ini memanfaatkan teknologi pengolahan suara dan teks sehingga kedua pengguna dapat saling bertukar pesan dengan cara yang sesuai dengan kebutuhan masing-masing.

BRIDGE hadir dengan tujuan menciptakan pengalaman komunikasi yang lebih mudah, nyaman, dan inklusif bagi semua pengguna.

## ✨ Fitur Utama

| Fitur                 | Deskripsi                                                                       |
| --------------------- | ------------------------------------------------------------------------------- |
| 🎙️ Speech-to-Text     | Mengubah input suara menjadi teks untuk membantu komunikasi pengguna tunanetra. |
| 🔊 Text-to-Speech     | Mengubah pesan teks menjadi suara agar dapat didengar oleh pengguna tunanetra.  |
| 💬 Text Communication | Memungkinkan pengguna tunarungu berkomunikasi melalui pesan teks.               |
| 📜 Chat History       | Mengakses riwayat percakapan sebelumnya.                                        |
| ↩️ Reply Message      | Membalas pesan tertentu dalam percakapan.                                       |
| 📡 Device Connection  | Menghubungkan perangkat melalui jaringan Wi-Fi atau LAN.                        |
| 📊 Status Panel       | Menampilkan informasi koneksi, peran pengguna, dan status sistem.               |

## 🎯 Tujuan Pengembangan

Pengembangan aplikasi BRIDGE memiliki beberapa tujuan:

- Menciptakan sarana komunikasi yang inklusif.
- Mempermudah interaksi antara pengguna tunanetra dan tunarungu.
- Memanfaatkan teknologi suara dan teks untuk mengatasi hambatan komunikasi.
- Meningkatkan aksesibilitas teknologi bagi penyandang disabilitas.
- Mengembangkan sistem komunikasi yang aman dan nyaman digunakan.

## 🛠️ Teknologi

Teknologi yang digunakan dalam pengembangan BRIDGE:

> Sesuaikan daftar berikut dengan teknologi yang benar-benar digunakan dalam project.

- Programming Language: Python
- Interface: Command Line Interface (CLI)
- Communication: Wi-Fi / LAN
- Speech Recognition: Speech-to-Text
- Voice Output: Text-to-Speech

## 🚀 Pengembangan Selanjutnya

BRIDGE masih dalam tahap pengembangan. Beberapa fitur yang direncanakan untuk pengembangan berikutnya antara lain:

- [ ] Integrasi database untuk menyimpan percakapan.
- [ ] Penyimpanan riwayat chat secara permanen.
- [ ] Peningkatan keamanan data dan privasi pengguna.
- [ ] Optimalisasi performa komunikasi antarperangkat.
- [ ] Pengembangan fitur aksesibilitas yang lebih baik.

## 💡 Mengapa BRIDGE?

Komunikasi merupakan kebutuhan setiap orang. Namun, keterbatasan aksesibilitas sering kali menjadi hambatan bagi penyandang disabilitas.

Melalui BRIDGE, kami ingin menunjukkan bahwa teknologi dapat menjadi jembatan untuk menciptakan komunikasi yang lebih setara.

**Because everyone deserves to communicate.**
